# Contract Guidelines

- Solidity＋HardhatでTDを実装・テストし、非forkローカルAnvil（chain ID 31337）で銀行APIとの接続を確認する。
- トークン単位、mint・振替権限、残高正本、運用への引落し方法は承認済みADRに従う。未決定の権限モデルを独断で補わない。
- 認証とPolicy判定を分離し、実際に実行する相手先・金額を認可対象に結び付ける。
- 外部呼出しがある場合は再入を考慮し、検証・状態更新・外部呼出しの順序を確認する。
- 残高整合性と許可した操作をHardhatテストで確認し、適用する不変条件・異常系の範囲は承認済みStoryに従う。
- Anvilの既知鍵をpublicチェーンで使わない。RPCは銀行backendからのみ利用する。
- 本プロジェクトにZK回路・Verifier・Forgeを追加することは、この移植の要件ではない。
