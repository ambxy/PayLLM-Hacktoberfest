# private/public間の資金移動

以下は本デモの設計を比較するためのモデルです。特定銀行の未公開方式を説明するものではありません。

| モデル | 確認すべき点 |
| --- | --- |
| 元資産をlockして別台帳で表現する | lockと発行の証拠、二重発行、解除条件 |
| 片側を償還して別側で発行する | 途中失敗時の請求権、換算、決済完了の定義 |
| 銀行在庫から別資産を供給する | 在庫不足、返却確認、元資産との対応、流動性 |

本デモはTDをlockし、別の銀行在庫から顧客へUSDCを供給します。USDC元本が銀行へ返却された証拠を確認して、元のlockからTDを解除します。TDをpublicへ同一資産として移動するbridgeではありません。[精算ADR](../../../docs/adr/0009-sepolia-settlement.md)

公開資料の比較では、資産の種類だけでなく銀行間決済の構造も区別します。[BIS Bulletin 73](https://www.bis.org/publ/bisbull73.htm)
